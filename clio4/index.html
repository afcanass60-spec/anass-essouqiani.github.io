Installer comme écran d'accueil :
1. Ouvre cette page dans Chrome sur l'écran de la Clio.
2. Menu ⋮ → Ajouter à l'écran d'accueil / Installer l'application.
3. Lance l'icône « Clio 4 » : elle s'ouvre en plein écran, sans barre.
4. Pour qu'elle s'ouvre au démarrage, utilise une appli comme Fully Kiosk Browser (« Start on boot ») ou les réglages de démarrage automatique de ton poste.
