# Guide d'utilisation

## 1. Premier lancement (15 minutes)
1. Créez votre compte (le premier est administrateur).
2. **Career Studio → Profil** — complétez ce qui manque (rien n'a été inventé) :
   - coordonnées (téléphone, ville, LinkedIn) ;
   - expérience **FedEx** : intitulé exact, dates, 3 à 5 missions réelles, technologies utilisées ;
   - dates de vos formations, langues (niveau d'anglais), certifications, projets (labs Proxmox, maquettes réseau, projets ESGI) ;
   - Préférences : **adresse de départ** (pour les temps de trajet réels), années d'expérience, rythme d'alternance.
   Ou importez votre CV (PDF/DOCX) : l'outil propose les éléments détectés, vous choisissez ce qui est ajouté.
3. **Paramètres** : vérifiez quelles sources sont opérationnelles.

## 2. Trouver des offres
- **Recherches & agent** : 3 recherches sont pré-créées (alternance infra/réseaux, cloud/DevOps/cyber, CDI/CDD junior). « Lancer maintenant » exécute immédiatement ; la fréquence (6 h, quotidienne, hebdo) s'applique si le planificateur est actif.
- **Offres** : filtres à gauche (contrats multiples, lieux + rayon, télétravail, trajet réel, salaire brut/net, date, niveau, typologie d'entreprise, conditions, score, sources). Tri par score, date, salaire ou trajet.
- **Importer** : collez une annonce LinkedIn/Indeed/WTTJ… (texte) ou l'URL d'une page carrière d'entreprise.

## 3. Lire une analyse
Ouvrez une offre : score par critère avec ses raisons, compétences indispensables/souhaitées couvertes, transférables et manquantes, points bloquants, publications regroupées. « Analyser avec l'IA » ajoute la lecture de Claude (bornée et vérifiée).

## 4. Préparer une candidature
« Préparer ma candidature » ouvre un parcours en 5 étapes :
1. **Analyse** : missions, besoins, mots-clés ATS, questions RH et techniques, questions à poser, pitch.
2. **CV adapté** : choix de la meilleure version, modifications listées, avertissements ; « Modifier chaque rubrique » ouvre l'éditeur (aperçu temps réel, modèles, couleurs, polices) ; export PDF/DOCX ; analyse ATS.
3. **Lettre** : style, informations sur l'entreprise (fortement recommandé), consignes ; édition + analyse qualité.
4. **Messages** : email, LinkedIn, formulaire, relance, réponse, remerciement.
5. **Validation** : le dossier (CV + documents cochés) est figé en PDF/DOCX et rattaché à la candidature. Rien n'est envoyé automatiquement.

## 5. Suivre
**Candidatures** : tableau Kanban (glisser-déposer) ou liste ; fiche avec historique, contacts, notes, date de relance (rappel automatique), documents envoyés. Envoi par email possible si SMTP configuré, après confirmation explicite.

## 6. Entreprises
Liste d'entreprises cibles pré-remplie (aéronautique, banque/assurance, ESN, cloud, cyber, public). Ajoutez l'URL carrière : l'ATS est détecté ; « Surveiller » vérifie la page chaque jour (planificateur actif requis).
